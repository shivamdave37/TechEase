## 📱 About TechEase

**TechEase** empowers senior citizens to master essential smartphone skills independently, safely, and comfortably:
- **Interactive Step-by-Step Lessons:** WhatsApp messaging, camera & gallery, QR scanning, Google Maps, Wi-Fi, safe internet browsing, and Cyber Safety & Scam Shield.
- **Spoken Voice Guidance (TTS):** Real audio read-aloud on every lesson step with gentle speech pace toggles (0.75x slow / 1.0x normal) for seniors who prefer hearing instructions.
- **Risk-Free Practice Sandboxes:** Simulated environments where elders can tap, practice, and learn with gentle feedback, hint support, and unlimited retries without fear of making mistakes.
- **Cyber Safety & Scam Shield:** Real-world training on spotting fake lottery messages, OTP protection, and handling suspicious caller demands.
- **Trusted Family Assistance:** One-tap quick emergency/family helper contact to send pre-written WhatsApp help requests without needing to type.
- **Achievements & Encouragement:** Daily learning streaks, senior badge showcases ("Tech Starter", "WhatsApp Star", "Scam Shield"), and celebration certificates.
- **Asynchronous Voice-Only Groups:** Simple hold-to-record voice chat with listen-before-send preview, so elders can stay connected with friends and family without needing to type small keys.
- **Community Safe Guide Hub:** Educational video guides contributed by members with a verified authenticity pledge against scams and misleading advice.
- **Senior Accessibility First:**
  - Dynamic real-time text scaling (85% to 135%) active across all screens and menus.
  - High-contrast bold mode + Eye Comfort Dark Mode for sensitive eyes.
  - 11 languages supported with native typography: English, Hindi, Gujarati, Bengali, Marathi, Telugu, Tamil, Urdu, Kannada, Punjabi, Spanish.
  - Auto-adapting layout: native full-screen mobile on phones, spacious desktop view with NavigationRail on laptops.
  - Two-finger pinch-to-zoom (up to 4x) with on-screen `+` and `−` buttons.
  - Masked phone numbers (`***-***-1234`) for privacy protection.

## 🚀 Quick Start for Developers

```bash
# Clone the repository
git clone https://github.com/shivamdave37/design-thinking-project.git
cd design-thinking-project

# Install dependencies
flutter pub get

# Run all 52 tests
flutter test

# Run on Chrome
flutter run -d chrome

# Build for Web
flutter build web --release
```
